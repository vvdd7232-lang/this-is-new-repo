# ⚡ AI Execute Runner — ИИ из браузера выполняет команды на твоём ПК

Аналог **Claude Code / Codex**, но прямо в обычных чатах **ChatGPT**, **Claude**, **Arena** и **Google AI Mode** (а также Gemini, Copilot, Grok, DeepSeek и др.):

1. ИИ пишет команду в блоке ```` ```execute ````
2. Под блоком появляется кнопка **▶ Выполнить**
3. Ты подтверждаешь → команда выполняется **на твоём ПК**
4. Вывод вставляется обратно в чат кнопкой **📥 В чат** → ИИ продолжает работу

```
┌─ ChatGPT / Claude ─────┐   ┌─ Расширение ────┐   ┌─ Твой ПК ─────────┐
│ ```execute              │──▶│ Кнопка ▶ +      │──▶│ server.py         │
│ ls -la                 │   │ подтверждение   │   │ 127.0.0.1:8765    │
│ ```                    │◀──│ Вывод + вставка │◀──│ sh·py·node·pwsh   │
└────────────────────────┘   └─────────────────┘   └───────────────────┘
```

> ⚠️ **Почему две части?** Расширение браузера **не может** само запускать программы на ПК (это запрещено безопасностью браузеров). Поэтому нужен маленький локальный сервер `server.py` — он и выполняет команды. Это стандартная схема (так работают Claude Code, Multimodal и др.).

## 🚀 Установка за 5 минут

### Шаг 0. Скачай проект

- **Простой вариант:** зелёная кнопка **Code** → **Download ZIP** → распакуй архив.
- **Через git:** скопируй ссылку из той же кнопки **Code** и выполни `git clone <ссылка>`.

### Шаг 1. Запусти локальный сервер

Нужен **Python 3.8+** (обычно уже есть; проверить: `python --version`).

```bash
cd server
python server.py
# Windows:  py server.py
```

Должно появиться:

```
AI Execute Runner — локальный сервер запущен
http://127.0.0.1:8765
```

✅ Проверь в браузере: открой http://127.0.0.1:8765/ping — должен вернуться JSON `{"status": "ok", ...}`.

Флаги сервера: `python server.py --port 9999 --cwd D:\projects --max-output 0` — свой порт, рабочая папка для команд, лимит вывода (0 = без лимита). Если запустить из системной папки (System32) — сервер сам перейдёт в домашнюю. Рабочую папку можно задать и в расширении: ⚙️ → «Рабочая папка».

> Сервер слушает **только 127.0.0.1** — доступен лишь с твоего ПК, из интернета к нему не достучаться.

### Шаг 2. Установи расширение в Chrome / Edge

1. Открой `chrome://extensions` (в Edge: `edge://extensions`)
2. Включи **«Режим разработчика»** (тумблер справа вверху)
3. Нажми **«Загрузить распакованное расширение»** → выбери папку `extension/`
4. Закрепи иконку ⚡ на панели

### Шаг 3. Проверь связку

1. Кликни по иконке расширения → должно быть **✅ Сервер на связи**
2. Открой https://chatgpt.com, https://claude.ai или https://arena.ai — справа внизу должен гореть зелёный бейдж **⚡ exec: online** (на Арене работает во всех режимах: Battle, Side-by-Side и Direct)

### Шаг 4. Дай ИИ специальный промпт

Открой файл **`SYSTEM_PROMPT.md`**, скопируй **короткий промпт** и отправь первым сообщением в чат. (Промпт есть и в попапе расширения — кнопка «📋 Скопировать промпт для ИИ».)

### Шаг 5. Пользуйся 🎉

Попроси: *«покажи какая у меня ОС и что лежит в текущей папке»*. ИИ ответит execute-блоком → жми **▶ Выполнить** → подтверди → **📥 В чат**.

## 🧩 Какие блоки выполняются

| Блок | Что делает |
|---|---|
| ```` ```execute ```` / ```` ```exec ```` | shell-команда (`bash` на Mac/Linux, `cmd` на Windows) |
| ```` ```execute-python ```` | python-скрипт (тем же Python, что запустил сервер) |
| ```` ```execute-js ```` | Node.js-скрипт (нужен установленный `node`) |
| ```` ```execute-pwsh ```` | PowerShell (Windows) |

Обычные ```` ```bash ```` / ```` ```python ```` **игнорируются** — это защита, чтобы примеры «для справки» случайно не запускались.

---

> 🔀 Среду выполнения можно переключить: список прямо на панели под блоком + в окне подтверждения (shell / powershell / python / node). ИИ задаёт начальное значение языком блока, последнее слово — за тобой. Выбор запоминается для каждой команды и переживает перерисовки чата и перезагрузку вкладки.

## 🤖 Автопилот (автовыполнение + автовставка + автоотправка)

В попапе расширения (клик по иконке ⚡):

1. **Автовыполнение новых execute-блоков** — команда запускается сама: расширение ждёт конца генерации ответа, показывает обратный отсчёт (по умолчанию 3 сек — окно отмены, кнопка «✋ Отмена авто») и выполняет.
2. **Автовставка вывода в поле ввода** — `[LOCAL EXEC RESULT]` сам появляется в поле чата.
3. **Автоотправка результата ИИ** — результат сам отправляется (нажимается кнопка Send, запасной вариант — Enter). Все три галочки вместе дают полный цикл как у Codex: ИИ пишет → выполняется → ИИ читает вывод → пишет дальше.

**Предохранители (включены всегда, отключить нельзя):**
- ⛔ Опасные команды (`rm -rf`, `sudo`, `format`, `curl|bash`…) **никогда** не выполняются автоматически — только вручную.
- 🛑 Лимит автозапусков на вкладку — настраивается в ⚙️ (по умолчанию **0 = без лимита**; поставь число, если боишься бесконечного цикла и жрущихся токенов).
- 🛑 Детектор зацикливания: одна и та же команда 3 раза подряд — автопилот останавливается.
- ⏭ Повторы не выполняются молча: команды из прошлых загрузок вкладки и блоки, уже бывшие на странице, пропускаются с запиской в чат — повтор только вручную кнопкой ▶.
- ⏱ Недогенерированные команды не запускаются: автозапуск ждёт, пока текст блока перестанет меняться.

> Лень искать попап? На самой панели под кодом есть кнопка «🤖 Включить авто» — включает полный автопилот в один клик.
>
> Начинай с первых двух галочек без автоотправки — посмотришь, как оно себя ведёт, потом включишь полный цикл.

## 🛡️ Безопасность (прочитай!)

- ✅ **Подтверждение каждого запуска** включено по умолчанию — ИИ ничего не выполнит без твоего клика. Не отключай без нужды.
- ⛔ На опасные паттерны (`rm -rf /`, `sudo`, `format`, `curl|bash`…) модалка покажет **красное предупреждение**.
- 🔒 Сервер слушает только `127.0.0.1`, вывод обрезается (1 МБ), есть таймаут (по умолчанию 30 сек).
- 🧱 Проверка `Host`/`Origin`: запросы с чужим Host (DNS-rebinding) или Origin (чужой сайт) отклоняются с `403`. Разрешены только локальные и `chrome-extension://`.
- 📏 Лимиты вывода (настраиваются, 0 = без лимита): сервер — до 1 МБ (`python server.py --max-output 0`), вставка в чат — до 32000 символов (поле в настройках ⚙️). При обрезке в результате есть пометка с лимитом.
- 🙅 Не давай ИИ доступ, когда отходишь от ПК; не подтверждай команды, которых не понимаешь.

> 🩺 Странный/пустой вывод? Смотри [TROUBLESHOOTING.md](TROUBLESHOOTING.md) — известные проблемы, настоящие причины и обходы.
- 💡 Для экспериментов можно запускать сервер из пустой папки или под отдельным пользователем.

## ❓ Не работает?

| Симптом | Что делать |
|---|---|
| В консоли мелькают `GET /ping` | Это не ошибка, а проверка связи для бейджа. С v1.1.1 ping по умолчанию не логируется; полный лог — `python server.py --verbose` |
| Нет кнопки ▶ под блоками | 1) После обновления расширения: `chrome://extensions` → 🔄, затем Ctrl+F5 на вкладке чата 2) Двойной клик по бейджу ⚡ — диагностика: сколько блоков найдено и что видит детектор (подробности в консоли F12) 3) Запасной вариант: выделите код → правый клик → «⚡ Выполнить выделенное локально» |
| Кнопки нет только на одном сайте | Напишите какой — добавлю селекторы. Временно — правый клик по выделенному коду |
| Бейдж **exec: offline** | Запущен ли `python server.py`? Адрес в попапе `http://127.0.0.1:8765`? |
| Кнопка ▶ не появляется | ИИ написал обычный ` ```bash `, а нужен ` ```execute `. Попроси переписать. Обнови страницу. |
| «Вставить в чат» не находит поле | Кликни в поле ввода сам и нажми Ctrl+V — вывод уже в буфере обмена. |
| `node: not found` | Для `execute-js` установи Node.js, либо проси ИИ использовать `execute-python`. |
| Firefox | Manifest V3 от Chrome совместим частично — проще использовать Chrome/Edge. |
| Автопилот не запускается | Проверь: галочка «Автовыполнение» + кнопка Сохранить; блок именно `execute` (не `bash`); вкладка чата обновлена после включения (Ctrl+F5) |
| Автоотправка не нажимает Send | Кнопка отправки ищется эвристикой — на редких сайтах может не найтись, тогда жмётся Enter. Напиши какой сайт — добавлю селектор |
| ИИ пишет execute не в блоке, а текстом | Включи «Нестрогий поиск» в настройках ⚙️ (включён по умолчанию): если слово execute стоит рядом с кодом отдельной строкой — появится панель EXECUTE? (по умолчанию только вручную; автозапуск — галочка «Автозапуск EXECUTE?» в ⚙️). Но лучше попроси ИИ писать правильный блок ` ```execute ` |

| Extension context invalidated в консоли | Норма после нажатия обновить на странице расширений: скрипт на открытой вкладке устарел. Просто обнови вкладку (F5). С v1.4.1 вместо спама ошибок будет один тост с подсказкой |
| WinError 10053 / aborted в консоли сервера | Браузер разорвал соединение раньше времени (пинг во время долгой команды). С v1.4.2 сервер многопоточный, а такие обрывы молча игнорируются. Если повторяется постоянно — проверь антивирус/прокси на localhost |

## 🔧 Настройки

Полная страница настроек — **все** параметры в одном месте. Открыть можно тремя способами:
- кнопка **«⚙️ Все настройки»** в попапе расширения;
- правый клик по иконке ⚡ → **Параметры**;
- `chrome://extensions` → **Сведения** → **Параметры расширения**.
