🖥 Локальный сервер

Программа server.py на твоём ПК — она и выполняет команды. Расширение только передаёт их.
Обычно http://127.0.0.1:8765. Если запускал сервер с другим портом — впиши его сюда.
Сколько ждать одну команду. Долгие (установка пакетов, тесты) — ставь 120–300.
Все команды будут выполняться в этой папке. Должна существовать на ПК, иначе сервер вернёт ошибку «cwd not found».
Запуск сервера: python server.py [--port 8765] [--max-output N] [--verbose]

🛡️ Подтверждения

Ручной режим: каждый запуск — только после твоего клика.

🤖 Автопилот

Полный цикл без рук: команда выполняется сама → вывод сам вставляется → сам отправляется ИИ.
Окно отмены с кнопкой «✋ Отмена авто». 0 — выполнять сразу после конца генерации.
Защита от бесконечного цикла, жрущего токены. Счётчик сбрасывается при перезагрузке вкладки.
Автопилот не выполняет повторно команды из прошлых загрузок вкладки (защита от прогона всей истории после F5). Повтор — вручную кнопкой ▶.
⚠️ Автопилот включён: команды будут выполняться БЕЗ подтверждения. Опасные (rm -rf, sudo…) — всё равно только вручную.

🔀 Среды выполнения

В чём запускать команды. Точный язык блока (execute-python и т.п.) всегда важнее этой настройки.
Используется для «Выполнить выделенное» (правый клик) и блоков EXECUTE?, где язык не распознан. На каждой панели среду можно переключить вручную — выбор запоминается автоматически.

📏 Лимиты вывода

Защита от гигантских выводов. 0 = без лимита (осторожно с токенами при автоотправке).
Сколько символов результата вставлять в поле ввода. При обрезке в тексте есть пометка с лимитом.
Лимит на стороне сервера (по умолчанию 1 МБ): python server.py --max-output 0
