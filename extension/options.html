Сервер и доступ порт, рабочая папка, токен
Программа server.py на твоём ПК — она и выполняет команды. Расширение только передаёт их.
Обычно http://127.0.0.1:8765. Если запускал сервер с другим портом — впиши его сюда.
Сколько ждать одну команду. Долгие (установка пакетов, тесты) — ставь 120–300.
Пусто = папка, из которой запущен сервер. Папка должна существовать, иначе сервер вернёт «cwd not found».
Если сервер запущен с токеном (по умолчанию), скопируй его из вывода python server.py — строка «Токен доступа: …». Хранится только локально (storage.local) и не синхронизируется между устройствами.
Whitelist: проверка не выполнена
Запуск сервера: python server.py [--port 8765] [--cwd PATH] [--max-output N] [--whitelist FILE]
Защита команд (whitelist). Если сервер запущен с флагом --whitelist FILE, выполняются только команды из файла (по префиксу). Цепочки, пайпы и переводы строк запрещены; view тоже подчиняется списку.
В режиме whitelist MCP отключается целиком: список проверяет shell-команды, а инструменты MCP — нет, поэтому их выполнение возвращает ошибку, а не проходит мимо защиты.

Автопилот полный цикл без рук
Команда выполняется сама → вывод сам вставляется → сам отправляется ИИ.
Автопилот включён: команды будут выполняться без подтверждения. Необратимо опасные — всё равно только вручную.
Окно отмены с кнопкой «Отмена авто». 0 — выполнять сразу после конца генерации.
Защита от бесконечного цикла, жрущего токены. 0 = без лимита. Счётчик сбрасывается при перезагрузке вкладки.
История выполненных команд …
Автопилот не выполняет повторно команды из прошлых загрузок вкладки — защита от прогона всей истории после F5. Повтор — вручную кнопкой «Выполнить».

Для «Выполнить выделенное» (правый клик) и блоков EXECUTE?, где язык не распознан. На каждой панели среду можно переключить вручную — выбор запоминается.

Хранит последние 30 команд: время, среда, код возврата. Вывод команд не сохраняется, токен доступа в журнал не попадает. Экспорт пригодится, если нужно вспомнить, что именно запускалось.
Лимиты вывода сколько текста вставлять
0 = без лимита. При обрезке в тексте есть пометка с лимитом. Лимит сервера (по умолчанию 1 МБ) задаётся флагом --max-output.
Что попадает в поле «$ …» сообщения [LOCAL EXEC RESULT]. «Кратко» заменяет длинные скрипты первой строкой и пометкой, «Скрыть» оставляет только счётчик — экономит место в диалоге.
Сколько строк показывать, если нажать на предпросмотр под панелью. 0 — весь текст целиком. По умолчанию 12: длинные скрипты не растягивают чат.

Оформление
Палитра, скругление, стиль кнопок и плотность — необязательные и применяются сразу.
Меняет акцентный цвет. Поверхности и текст остаются за темой — поэтому палитра читается и в светлой, и в тёмной.
«Плиточное» — без скруглений вообще: строгий технический вид.
«Заливка» — кнопки цветные, «контур» — только рамка, «плитка» — прямоугольные без рамок.
Компактно — больше вывода на экран, просторно — крупнее шрифт и отступы.

MCP — внешние MCP-серверы экспериментально
Подключение внешних MCP-серверов: ИИ получает их инструменты и вызывает их блоком execute-mcp с JSON внутри — например, {"server":"blender","tool":"create_cube","arguments":{"size":2}}.
Браузер не умеет запускать процессы, поэтому MCP-серверы поднимает локальный сервер — его нужно запустить с флагом --mcp и включить нужные серверы в server/mcp_servers.json. Поддерживается только stdio-транспорт.
Состояние не проверено
Запустите сервер с флагом --mcp и включите нужные серверы в server/mcp_servers.json.
