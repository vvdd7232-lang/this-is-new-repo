# v2.11.3 — понятный промпт и автопилот

Патч-релиз: системный промпт для ИИ переписан — понятнее и короче для восприятия моделью, а про автопилот он теперь говорит явно и сам подставляет нужный раздел, когда автопилот включён.

## Промпт для ИИ: яснее

- **Правила вынесены наверх.** В начале появился блок «САМОЕ ВАЖНОЕ — ТРИ ПРАВИЛА»: команда только в блоке `execute`, язык блока = язык кода, один блок = одна команда. Модель видит главное, не дочитывая текст до конца.
- **Таблица сред стала заметнее.** Ошибка «python в простом `execute`» подчёркнута прямо под таблицей.
- **Список частых ошибок расширен** под MCP: выдуманное имя сервера/инструмента, пропущенные `arguments`, MCP там, где хватит обычной shell-команды.

## Автопилот: говорится явно

- **Отдельный раздел `AX_AUTOPILOT_SECTION`** объясняет ИИ, что при включённом автопилоте блоки выполняются и результат приходит сам: работай автономно по шагам, не переспрашивай на безопасных шагах, опасное — сначала текстом без блока.
- **Раздел подставляется по факту настройки.** Новая функция `AX_buildPrompt(on)` добавляет раздел про автопилот только если включён «Автовыполнение». Кнопка «Скопировать промпт для ИИ» в попапе и на странице настроек теперь копирует ровно то состояние, с которым пользователь реально работает.
- **`SYSTEM_PROMPT.md` синхронизирован:** короткий вариант совпадает с `AX_PROMPT`, а раздел про автопилот вынесен отдельно — его видно и можно добавить вручную.
